# 可视化微调 · 交互与验证

## v1.4.0 图片资源

- 使用 PostCSS 与 postcss-value-parser 读取声明内的 url()，按声明/出现次序定位；同链接不同位置分别替换，保留媒体条件、其他图层、!important 与附近注释。
- 图片资产独立保存在本次编辑的内存中，撤销记录只存资产引用，避免每次头像加减都复制内嵌图数据。
- 换图预览使用完整草稿，并暂时将原生 style 的 media 设为 not all；原 CSS 文本保持不变。关闭、撤销全部图片和保存时恢复原 media。只有部位调整时仍只追加微调样式。
- 相册文件最大 20 MB，静态图缩到最长边 1600px、WebP 质量 0.85（不支持的浏览器回退 PNG），处理结果约 2 MB 内；GIF 不重编码、最大 2 MB。其他动画格式可能静态化；浏览器无法解码的 HEIC 等格式提示改用 JPG/PNG/WebP。
- 仅在本机 FileReader/Canvas 处理，没有图床上传。支持 HTTP/HTTPS、相对路径和图片 data URL；不接受临时 blob URL。原始内嵌图不会将长字符串填满输入框，仍显示真实缩略图。
- 首版不读取 image-set() 中仅使用字符串的图片、字体、@import 或聊天消息中的图片。背景、遮罩、内容图片、列表图标、光标与自定义变量内的 url() 会列出；缩略图失败时仍可替换。
- 28 项自动测试通过；390×844 模拟宿主验证 2400×1200 PNG 自动转为 1600×800 内嵌 WebP、实际封面变化、撤销/重做与保存。真实 ST/TT 手机端待回归。

## v1.3.0 保存到原美化

- 「保存当前美化」更新原主题，不新增名称或副本。使用原生 CSS 输入和更新按钮，核实持久化 CSS 后结束预览。
- 保存前阻止主题切换或 CSS 被外部修改造成的误覆盖；保存失败或结果不明时显示具体错误。
- 首页「直接注入原美化」只处理选中的已安装主题；「生成副本并应用」继续保留。
- 加减号与撤销/重做 SVG 在按钮内水平、垂直居中。
- 验证：22 项自动测试通过；390×844 浏览器视口测量按钮与 SVG 中心对齐。模拟宿主中圆角 6→7 保存后重新打开为 7，首页切换选中美化并直接注入后仍为 3 款。真实手机 WebView 待回归。

## v1.2.0 底栏扩展

- 删除「一点点，调成喜欢的样子」标题，撤销/重做使用圆润 SVG 箭头。
- 「底部输入栏 → 上下位置」以进入编辑时为 0，正数抬高、负数降低；使用独立 translate，不改 bottom、position、transform 或键盘变量。范围 -120 到 200px。过量下移可能进入系统手势区或被父容器裁切，可用手柄中间的还原按钮恢复。
- 「底部留白」相对当前 padding-bottom 调整，范围 -120 到 200px，总留白最低为 0。识别到 TT 标准安全区或本编辑器生成的安全区规则时，保留动态 --tt-inset-bottom 表达式；其他美化以当前像素留白为基线。
- 微调可能改变底栏视觉位置或覆盖邻近聊天内容，不承诺任意主题无冲突。原生键盘行为交给宿主，不会全局重置安全区变量。
- 手柄默认显示在上方，避免覆盖底栏；原头像操作保留。
- 19 项单元测试通过。手机 390×844 预览检查：底栏 +5px 上移、-5px 下移；TT 模拟安全区 34px 调整为 29px，安全区切换到 0 后总留白为 0；模拟键盘收缩 180px 时底栏随宿主移动且微调值不丢失。模拟入口为 `?layout-test=1`，测试夹具不进入扩展发行文件。
- 尚未在真实 TT WebView 上验证新版底栏行为。

新增工作室首页「可视化微调」入口。读取当前激活且已保存的主题，在真实聊天 DOM 上预览；本地 preview 页使用示例聊天和模拟宿主，所有保存仅在本页内存中，刷新会重置。

支持角色头像、用户头像的圆角、方形尺寸、位置、边框；支持数值输入、滑条、1/5px 步长、长按、浮动手柄拖动、屏幕点选、撤销/重做、恢复当前项目、恢复全部、导出主题 JSON，以及通过原生更新流程保存当前美化。作者注释使用 PostCSS 按源码顺序提取，可搜索并查看附近代码；不自动推断任意注释的含义。

预览写入单独的 style 元素，保留原主题 CSS。位移使用独立 translate 属性，保留 transform；复杂的非像素 translate 暂停位置微调。修改以追加 CSS 形式导出，不直接改写作者声明。重复编辑已保存美化会在其基础上再追加一个调整区，后续版本可引入可合并的编辑元数据。

切换主题或外部更改当前 CSS 时结束编辑；关闭编辑器清除临时 style。保存时暂时移除预览、隐藏编辑器，通过酒馆原生更新按钮保存，再核实原美化记录。
