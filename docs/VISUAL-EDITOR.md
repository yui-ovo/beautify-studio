# 可视化微调 · 第一版交互原型

## v1.2.0 底栏扩展

- 删除「一点点，调成喜欢的样子」标题，撤销/重做使用圆润 SVG 箭头。
- 「底部输入栏 → 上下位置」以进入编辑时为 0，正数抬高、负数降低；使用独立 translate，不改 bottom、position、transform 或键盘变量。范围 -120 到 200px。过量下移可能进入系统手势区或被父容器裁切，可用手柄中间的还原按钮恢复。
- 「底部留白」相对当前 padding-bottom 调整，范围 -120 到 200px，总留白最低为 0。识别到 TT 标准安全区或本编辑器生成的安全区规则时，保留动态 --tt-inset-bottom 表达式；其他美化以当前像素留白为基线。
- 微调可能改变底栏视觉位置或覆盖邻近聊天内容，不承诺任意主题无冲突。原生键盘行为交给宿主，不会全局重置安全区变量。
- 手柄默认显示在上方，避免覆盖底栏；原头像操作保留。
- 19 项单元测试通过。手机 390×844 预览检查：底栏 +5px 上移、-5px 下移；TT 模拟安全区 34px 调整为 29px，安全区切换到 0 后总留白为 0；模拟键盘收缩 180px 时底栏随宿主移动且微调值不丢失。模拟入口为 `?layout-test=1`，测试夹具不进入扩展发行文件。
- 尚未在真实 TT WebView 上验证新版底栏行为。

新增工作室首页「可视化微调」入口。读取当前激活且已保存的主题，在真实聊天 DOM 上预览；本地 preview 页使用示例聊天和模拟宿主，所有保存仅在本页内存中，刷新会重置。

支持角色头像、用户头像的圆角、方形尺寸、位置、边框；支持数值输入、滑条、1/5px 步长、长按、浮动手柄拖动、屏幕点选、撤销/重做、恢复当前项目、恢复全部、导出主题 JSON，以及通过原生导入流程另存并应用副本。作者注释使用 PostCSS 按源码顺序提取，可搜索并查看附近代码；不自动推断任意注释的含义。

预览写入单独的 style 元素，保留原主题 CSS。位移使用独立 translate 属性，保留 transform；复杂的非像素 translate 暂停位置微调。修改以追加 CSS 形式导出，不直接改写作者声明。重复编辑已保存副本会在其基础上再追加一个调整区，后续版本可引入可合并的编辑元数据。

切换主题或外部更改当前 CSS 时结束编辑；关闭编辑器清除临时 style。保存时暂时移除预览、隐藏编辑器，让酒馆导入对话框可操作，再核实保存副本。
